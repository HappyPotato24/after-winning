# 赢过以后

中文、单机、离线的预测份额交易与开放人生故事模拟。所有金额均为虚拟 U。

## 开始游玩

使用 Chrome、Edge 或现代浏览器直接打开 `dist/赢过以后.html`。文件包含全部 HTML、CSS、JavaScript，不需要网络、安装依赖、服务器或登录。

开局有两种方式：直接选择“普通上班族”“背债者”“有房有积蓄”“赌狗”四个默认角色之一，或使用“按你的情况开局”填写自己的生活账本。自定义字段包括银行存款、生活债务、每日收入、每日生活费、借款总额度、房产/汽车/电脑/其他资产价值。输入框初始为空，统一显示“请输入”；没有的项目请显式填写 0。金额可为 0，最多两位小数，每项上限 1,000,000,000 U；资产价值为 0 时不创建该资产。交易本金始终固定为 10,000 U。

自定义角色按顺序自动判定：存款小于 5,000 U → 赌狗；其余有债务 → 背债者；其余有房、存款至少 100,000 U 或生活资产合计至少 500,000 U → 有房有积蓄；其余 → 普通上班族。5,000 U 本身不属于“小于 5,000”。开局表单实时展示判定与净资产，角色类别在开局确定，收入、债务与实际是否有房共同影响开场故事。直接选择默认角色时保留所选设定，不执行自动分类。

选择人物后，点击“开始引导行情”，再确认剧情订单。两局引导采用逐段直线插值的折线行情，实时展示折返与逆转，各经历约 5 秒：第一局全额 10,000 U、0.01 U 买入涨份额，含费结算 980,392.16 U；第二局投入该余额一半、0.50 U 买入涨份额，固定失败后保留 490,196.08 U。读完剧情后手动开启自由行情。

第三局起可自选金额、方向和 1/2/5/10 倍逐仓杠杆，支持同轮加仓、部分卖出、全部卖出和空仓观察。24 小时周期的分时线末端点与最后一段连线实时跟随行情移动，每现实 10 秒（游戏内 10 分钟）把当时位置固定为历史点，保留开盘点与结算点。实时末端只用于绘图，不写进固定历史；报价、成交和强平仍每 0.25 秒模拟。暂停和离线不累计采样时间，快进会依次记录途经的采样点。旧存档已经存在的历史点保留，后续按新间隔采样。新周期只影响下一轮。暂停、切换标签、弹窗、刷新与恢复存档都会冻结行情，需要主动恢复。轮间不自动开局。

“生活与资产”页可以提现、转入、工作、休息、借款、还款和变卖。生活时间快进会逐步处理本轮持仓，不跳过强平和结算；每天 0 点结算生活费及债息。工资在工作一天结束后进入银行。银行不足的生活费用形成生活欠款。出售房屋和汽车会影响后续生活成本或工资。

“把日历多翻几页”支持一次快进 1～3,650 个完整日，可用 7/30/90/365 天快捷选项，也可自行输入整数天数。选择“每天工作并快进”会在每天结束后领取工资；“休息并快进”没有工资。每日生活费、欠款和复利逐日计算，逐日记录账单和工资，剧情只汇总一次。现有持仓会依次经过行情、强平或结算，当前轮次结束后不自动开启新轮次。快进结束时暂停。操作先在候选状态完整模拟，通过存档校验后再应用；数值或记录数量越界时保留原故事。

“调整生活收支”可随时在引导结束后修改当前实际每日工作收入和每日生活费。输入框默认显示“请输入”，留空的项目不修改，0 表示没有该项收入或开支；每项上限为 1,000,000,000 U。确认后仅影响后续工作与每日结算，不补发工资、不回退日期、不重算旧账，也不改写人物初始配置。这里设置的费用是包含现有租金、通勤的实际总额；以后再变卖房车仍按原规则调整当前数值。


“人生轨迹”记录实际事件，点击节点查看当时资产。百万、账户归零、负净资产等是经历，均不自动结束故事。“收手离场”按当前价格平仓，之后封存故事。虚构人物的“跳楼”选项位于生活页折叠菜单，需要确认，可取消，不描写过程、不奖励、不豁免债务。结束后点击“重新开始”，可以选择“不导出，重新开始”或“导出后重新开始”，也可以取消。直接重开会清除当前故事的浏览器本地记录，回到人物选择；已有 JSON 文件不受影响。

## 保存

浏览器本地自动保存；离线期间不追算行情。右上角“存档”支持 JSON 导出与导入。导入校验版本、结构、数值和仓位关系，覆盖前自动导出当前故事；导入后暂停。v1 新增尾数、轮内盈亏字段有缺省迁移；自定义开局使用可选的 `origin` 初始配置，旧版不带该字段的默认人物存档仍可读取，不改变既有现金、债务和仓位数量。

JSON 是完整的游戏存档，包含人物背景、游戏时间、交易余额、银行存款、生活债务、资产、工资与开支、持仓及逐仓融资、当前行情和随机数状态、全部交易流水、剧情节点、里程碑和结束状态。金额按整数“分”保存，例如 `cash: 1000000` 代表 10,000 U；`time` 的单位为游戏内分钟。它不包含真实交易账户或登录凭据。未结束的故事导入后可从暂停状态继续；已结束故事导入后只恢复封存的结果与轨迹。

浏览器对本地文件的 localStorage 行为可能不同。移动文件、清理浏览数据、隐私模式或更换浏览器可能使原本地记录不可见，重要记录请导出 JSON。导出文件由浏览器决定下载位置。

## 模拟规则

- 标的采用独立高斯对数随机游走，固定轮内漂移；份额价格依据当前位置与剩余波动计算，限制于 0.01～0.99 U。随机生成过程不读取下注方向、金额、杠杆或盈亏。仅前两局固定。
- 结算时标的收盘高于开盘判涨，否则判跌；正确份额兑付 1 U，错误份额归零。
- 手续费：价格不高于 0.50 时为成交额的 2%；高于 0.50 时为 `2% × (1−p) ÷ p`。买入总支出包含费用，提前卖出收费，结算兑付不加收费。
- 现金以整数分记账，份额保留 8 位小数。买入份额按未提前取整的成交成本计算；部分卖出毛款不足一分的尾数留在原仓位，最后一次统一取整，避免拆单多返资金。
- 杠杆是游戏添加的逐仓融资，无融资利息；净清算权益不高于保证金 12% 时强平，亏损不超过该笔总支出。部分卖出按比例处理融资。生活借款单独计息，每日 0.03% 复利。
- 持仓权益已经扣除融资，尚未扣除未发生的卖出费用；总净资产＝交易现金＋持仓权益＋存款＋剩余资产账面价值−生活债务。转账、借入和还款均不会直接改变净资产。

## 开发与验证

请始终从 WSL 编辑与构建本项目，避免 Windows 文件加密软件影响文件内容。

```sh
cd /home/ubuntu/Potato
node build.cjs
node tests/engine.test.cjs
node tests/life-extensions.test.cjs
```

`src/characters.js` 为默认角色、自定义配置和自动故事，`src/core.js` 为状态和报价，`trading.js` 为行情及交易，`life.js` 为生活，`story.js` 为事件与里程碑，`save.js` 为存档校验，`ui.js` 和 `style.css` 为界面。`src/engine.js` 与交付 HTML 均由构建脚本生成，不应直接修改。

`tests/browser.test.cjs` 是本机 Chrome 的交互验收工具，通过独立临时浏览器配置运行，并把截图、结果交给 WSL 写入；可在 Windows 项目目录执行 `node tests/browser.test.cjs`。该工具需要本机 Chrome 及 WSL，不是游戏运行依赖。它临时使用 8765/9223 端口，结束后关闭所启动的服务与浏览器。游戏本体没有任何网络请求。

验证覆盖两局真实等待、随机路径独立性、各周期比例、买卖与逐仓清算、生活与资产、暂停恢复、旧档迁移、界面 JSON 往返、桌面和 390px 手机布局、离线文件打开。截图与浏览器结果在 `tests/`。

## 首版限制

仅一个模拟指数；价格模型采用有限时间步长，概率作边界截断，不模拟真实流动性、滑点、订单簿和外部金融平台。人生事件使用本地中文模板与实际状态组合，属于轻量故事系统。轨迹按真实发生顺序延伸，没有预制结局树。当前浏览器保存一个活动故事，其他故事通过 JSON 独立归档。
